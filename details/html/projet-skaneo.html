Skaneo – Application mobile de scan de cartes de recharge

Une application mobile conçue pour rendre les recharges plus simples au quotidien à Madagascar. Skaneo est le produit principal ; son site sert à présenter et télécharger l’application.

Le problème

Saisir manuellement un long code de recharge peut être lent et source d’erreurs. Il est aussi peu pratique de devoir reprendre le processus pour chaque carte, ou de dépendre d’une connexion Internet pour effectuer une opération simple. Skaneo vise à alléger ces étapes pour les utilisateurs des opérateurs Yas, Orange et Airtel.

La solution

L’application Android utilise la caméra ou une image importée pour lire le code de recharge avec l’OCR, reconnaître l’opérateur et préparer la commande USSD. Elle permet aussi d’enchaîner plusieurs scans, de préparer des commandes de retrait Mobile Money et d’utiliser l’interface en français ou en malgache. Le traitement se fait hors ligne, sans compte.

Technologies

Application mobile : React Native, Google ML Kit, React Native Notifications et AsyncStorage.

Site de présentation : HTML, CSS, JavaScript vanilla, Redis et Vercel.
